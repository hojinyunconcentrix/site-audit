# Architecture

출시 전 QA용 로컬 웹 검수. 화면과 수집은 Python이고, 공용 DB는 없다.

```mermaid
flowchart LR
  사람[사람] --> 입력[URL 입력]
  입력 --> 수집[공개 페이지 수집]
  수집 --> 분류[유형 분류]
  분류 --> 목록[단계별 목록]
  목록 --> 최근[이 브라우저 분석 저장]
  최근 --> 엑셀[엑셀 다운로드·업로드]
```

글 흐름: 사람이 루트 URL을 넣으면 그 페이지의 GNB·FNB를 한 번 읽어 메뉴 단계로 보여주고, 그 분석을 이 브라우저에만 남긴다. 그 결과는 엑셀로 내려받고 다시 올릴 수 있다.

## Modules

| 경로 | 역할 |
| --- | --- |
| `src/site_audit/server.py` | 화면과 API. `127.0.0.1`만 연다. |
| `src/site_audit/guard.py` | 공개 http(s), 80/443만 허용. 사설망·계정 포함 주소 거부. |
| `src/site_audit/http_fetch.py` | 리다이렉트마다 다시 검사하고, 확인한 IP로만 연결. 같은 호스트는 동시에 2연결, 요청 시작 간격 0.4초. 403·429·503이면 한 번 재시도 후 그 호스트를 멈춘다. |
| `src/site_audit/audit.py` | 하위전체 검색은 입력 페이지의 GNB·FNB를 한 번만 읽어 메뉴 단계로 만든다. 주소가 있는 항목을 읽어 `productListApi`가 상품 목록 API를 가리키면 PLP, `data-count-url`이 저작 API를 가리키면 PDP, 그 외는 일반으로 둔다. 호출 수는 호스트 제한을 따른다. 그 페이지에서 링크는 더 모으지 않는다. 메뉴가 없으면 입력한 경로 아래를 경로 깊이로 모은다. 통과·실패 검사는 깊이 2, 최대 50페이지. |
| `src/site_audit/report.py` | CSV. |
| `src/site_audit/rules.json` | 경로 표식, UFN 문자열, 썸네일 픽셀, PLP 수량 정규식. 비어 있으면 전용 검사를 통과로 적지 않는다. |
| `src/site_audit/static/` | 접을 수 있는 단계 목록. 분석은 `localStorage`. 하위전체 검수 엑셀은 `xlsx.js`가 브라우저에서 만들고 읽는다. |

## Data

- 페이지 원문은 요청 메모리에만 있고, 끝나면 버린다.
- 서버에 팀 공용 기록을 두지 않는다. 진행 중 작업만 프로세스 메모리에 잠시 있다. 다른 화면에서도 그 작업이 보이고, 중지는 지금 보는 페이지 확인이 끝난 뒤 반영된다.
- 하위전체 검수 결과는 엑셀로 내려받는다. 그 파일을 올리면 이 브라우저의 최근 검사로 다시 들어온다. 통과 보고서 CSV는 별도다.
- 최근 분석은 이 브라우저의 `localStorage`다. 같은 주소는 다시 분석하기 전에 확인한다.

## Boundaries

- 쿠키, 비밀, 토큰을 대상 사이트로 보내지 않는다.
- 다른 호스트 링크는 깨짐 여부만 보고, 페이지 목록에는 넣지 않는다.
- 수집 상한에서 못 본 주소는 통과 행으로 넣지 않는다.
